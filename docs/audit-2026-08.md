## 2. Stack technique

Le site est **100 % statique** : zéro build, zéro framework, zéro dépendance runtime hors Google Fonts.

| Couche | Technologie | Notes |
|---|---|---|
| Markup | HTML5 (11 pages) | +2 depuis juin (hermes.html, login.html) |
| Styles | CSS3 — 1 fichier, BEM, custom properties | 1 591 lignes |
| Scripts | JS vanilla ES5 — 2 fichiers | main.js + meteo.js |
| Thème | Jour/nuit via `data-theme` + `localStorage` | Défaut : **jour** (`light`) |
| Police | Google Fonts (Inter + Space Grotesk) | `@import` CDN + `preconnect`/`preload` |
| Météo | Open-Meteo Forecast API (gratuit, sans clé) | |
| Géocodage | Open-Meteo Geocoding + Nominatim/OSM | |
| Cache-busting | `?v=timestamp` sur CSS/JS | `v=1785757465` (CSS) `v=1785752541` (JS) |
| Hébergement | Nginx — fichiers statiques | |
